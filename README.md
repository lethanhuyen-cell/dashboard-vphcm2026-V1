# Dashboard Báo Cáo Điều Hành & Đối Soát Số Liệu
## VPĐD Báo Lao Động tại TP.HCM (2025 - 2026)

Hệ thống dashboard giám sát toàn diện 3 cấp độ (Tuần, Tháng, Quý), đối soát cùng kỳ YoY (2025 vs 2026) và đánh giá 22 phóng viên chính thức.

### 🚀 Deploy lên Vercel:
1. Push repository này lên GitHub.
2. Truy cập [vercel.com](https://vercel.com) -> New Project.
3. Import repo từ GitHub -> Deploy (chọn Framework: Other / Static Site).
